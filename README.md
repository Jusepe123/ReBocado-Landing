# ReBocado · Landing

Landing estática en español, basada en `../ReBocado.md` y el logo original. No requiere instalación ni compilación: publica el contenido de `dist/`.

## Vista local

Desde esta carpeta: `node server.mjs`. Abre `http://127.0.0.1:4173`.

## Contacto

Edita `dist/config.js` con el WhatsApp real (código de país y número, sin + ni espacios) o el correo del negocio. Los botones abren un mensaje específico para consumidores o comercios. Mientras no se configure el contacto, explican que el canal aún se anunciará. No se recopilan datos ni se simulan registros.

## Contenido y marca

`dist/index.html`: texto y secciones. `dist/styles.css`: estilos y tamaños de pantalla. `dist/app.js`: menú móvil, ejemplos de packs y ventanas de participación. `dist/assets/`: logo e imagen del hero.

La página distingue el piloto por WhatsApp de la aplicación en desarrollo. No contiene comercios afiliados ficticios, testimonios ni cifras de impacto.
